# Earth textures

Day map and cloud map by Solar System Scope / INOVE, based on NASA imagery.

Source: https://www.solarsystemscope.com/textures/

License: Creative Commons Attribution 4.0 International (CC BY 4.0)
https://creativecommons.org/licenses/by/4.0/

The original 2K JPEG textures are unmodified. The application shader adds spherical projection, lighting, atmospheric glow and animation. These are illustrative textures, not live weather.
